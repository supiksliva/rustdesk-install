# RustDesk Server & 3X-UI Auto-Install

Скрипт для быстрой автоматической установки сервера RustDesk (`hbbs` и `hbbr`) и панели 3X-UI (Xray / VPN) на VPS (Linux).

## Установка в одну команду

Подключитесь к вашему серверу по SSH и выполните:

```bash
bash <(curl -sSL https://raw.githubusercontent.com/supiksliva/rustdesk-install/main/install.sh)
```

### Меню выбора:
При запуске скрипт предложит выбрать вариант:
1. **RustDesk Server** — нативный сервер удаленного доступа (ID/Relay).
2. **3X-UI (VPN панель)** — последняя официальная версия панели управления Xray/VLESS.
3. **Всё вместе** — установит и RustDesk, и 3X-UI на один сервер.

### Особенности:
* Автоматически определяет внешний IP сервера.
* Предлагает ввести собственный домен или использовать IP.
* Настраивает службы `systemd` и открывает нужные порты в файрволе.
* Выводит в консоль готовый адрес сервера и публичный ключ для клиента RustDesk.
